Build a responsive web application called **RTR-TradeScope**.

RTR-TradeScope is a professional trading journal, analytics, and alert-management platform for active traders.

It does **not** execute trades and must not connect to a broker for order placement.

The purpose is to help traders:

* Record completed and planned trades
* Analyze historical performance
* Identify strengths and weaknesses
* Review strategy performance
* Manage price alerts
* Improve trading discipline

## Product Identity

Name: **RTR-TradeScope**

Tagline:

**Track. Review. Refine.**

The design should feel like a serious professional trading platform.

Use:

* Dark premium dashboard
* Clean financial UI
* Strong typography
* Minimal visual noise
* Professional charts
* Clear data hierarchy
* Responsive desktop-first layout

Do not copy TradingView, MetaTrader, or another product directly.

Create an original interface.

## Frontend Architecture

Build the frontend cleanly so that mock data can later be replaced with API calls.

Use reusable:

* Components
* Hooks
* Types/interfaces
* Services
* Page layouts

Keep API-related logic separated from UI components.

Create a service layer prepared for these future endpoints:

POST /api/trades

GET /api/trades

GET /api/trades/{id}

PUT /api/trades/{id}

DELETE /api/trades/{id}

GET /api/analytics/summary

GET /api/analytics/performance

GET /api/analytics/instruments

GET /api/alerts

POST /api/strategies
